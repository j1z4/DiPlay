# OpenPlay UI library

A minimal component library and interactive walkthrough for the OpenPlay head-unit UI. OpenPlay is a fork of DiPlay.
It combines three sources: the layout of the Figma frame (the device card on the left, the wordmark on the right), the focus model of Apple TV settings, and the information architecture of the current Android app.

It has no build step and no dependencies apart from the Outfit web font.

## View it

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8765 --directory design/ui-library
# then open http://127.0.0.1:8765/
```

Use the sidebar, or the Previous / Next links at the bottom of each page, to walk through it.
The **Walkthrough** page runs the whole app flow in a 1280 × 720 head-unit frame.
Drive it with the mouse, or use the keyboard as a D-pad: arrow keys to move, `Enter` to select, `Esc` to go back.
You can deep-link to a screen with `#walkthrough/home`, `connecting`, `failed`, `settings` or `setup`.

## Files

| File | Holds |
| --- | --- |
| `tokens.css` | Color, type, size, spacing, shape and motion variables, with night (default) and day (`[data-dp-theme="day"]`) themes |
| `components.css` | Every `dp-*` component; it reads only tokens |
| `components.js` | `window.DP`: switches, segmented controls, sliders, `DP.dialog()`, `DP.toast()`, and the D-pad focus engine `DP.focus` |
| `icons.js` | The app's `ic_dp_*` vector drawables as SVG, generated by `build_icons.py` |
| `screens.css`, `prototype.js` | The walkthrough screens, built only from components |
| `library.css`, `library.js`, `index.html` | The library site itself |
| `selftest.html` | A headless check of the D-pad flow (rail, pane, picker, dialog, connect) |

## Logo and splash (`brand/`)

| File | Use |
| --- | --- |
| `diplay-mark.svg` | The mark, cleaned from `~/bootanimation/logo.svg` (one path, without the Figma stroke mask) |
| `diplay-mark-outline.svg` | The outline only, to trace in other tools |
| `diplay-splash-trace.svg` | The animated trace (2.6 s), self-contained; open it in a browser |
| `avd_diplay_splash.xml` + `diplay_mark_path.xml` | The Android 12+ splash icon (AnimatedVectorDrawable, 1000 ms). Copy them to `res/drawable/` and `res/values/` |

In pages, `<i data-dp-mark>` renders the mark (`data-dp-mark="mono"` for one color), and `<div data-dp-splash>` renders the trace. `DP.replaySplash(el)` plays it again.

## Rules carried over from the app

- Corner radius follows control height: `min(24px, h × 20/56)` for buttons and `h × 14/56` for rows, as in `DiPlayButton.kt`.
- Gaps come from named spacing tokens (`--dp-row-gap`, `--dp-block-gap`), never literals (`AGENTS.md`, "Settings layout").
- Every interactive element shows focus for D-pad and rotary users. Rows invert to the focus fill; buttons get a ring.
- `prefers-reduced-motion` drops every animation to an instant cut.

## Regenerate icons

```sh
python3 design/ui-library/build_icons.py
```

## Self-test

Serve the folder as above and open `selftest.html`. The page drives the walkthrough with synthetic key presses and prints PASS/FAIL lines.
